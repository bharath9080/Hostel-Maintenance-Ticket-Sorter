# Project Reflection – Hostel Maintenance Ticket Sorter

## Introduction

The Hostel Maintenance Ticket Sorter is an AI-based project developed to improve the process of handling student maintenance complaints. The main objective is to classify complaints, identify urgent issues, assign maintenance teams, and organize tickets efficiently.

## Learning Experience

Through this project, I learned how artificial intelligence and Python programming can work together to solve real-world problems. I understood how an LLM can extract useful information from natural-language complaints and return structured JSON output.

I also improved my knowledge of Python concepts such as functions, dictionaries, lists, file handling, CSV operations, exception handling, regular expressions, and date calculations.

## Challenges Faced

One of the major challenges was designing a reliable prompt that produces consistent JSON responses. Another challenge was validating room numbers and identifying urgent complaints correctly.

Duplicate detection was also an important challenge because multiple students may report the same maintenance problem. I addressed this requirement by using room number and issue category as the identification criteria.

Testing the program and organizing the output reports helped me understand the importance of systematic software development.

## Importance of Human Supervision

I learned that AI should not make every decision independently, especially when safety is involved. The system can identify urgent complaints and organize maintenance tickets, but the warden must review urgent cases, assign work, and confirm completion before closing tickets.

This approach improves accountability and reduces the possibility of inappropriate automated decisions.

## Future Improvements

In the future, the project can be improved by completing live LLM integration through an approved API connection, developing a graphical user interface, adding student login facilities, and providing real-time ticket status updates.

Additional testing with different complaint formats can also improve the reliability of the classification system.

## Conclusion

Overall, this project helped me understand how AI can be combined with traditional programming to develop practical solutions. It improved my technical knowledge, problem-solving ability, and understanding of responsible AI development. I also learned that testing, validation, documentation, and human supervision are essential parts of building a reliable AI application.
